# Phrase prosody v1 — technical extraction investigation

This directory contains deterministic synthetic controls, not participant recordings or clinical norms. No UI or HTTP endpoint is added. Vowel, DDK, phrase 7A, 7B.1 and 7B.2 are unchanged.

Reproduce development:

```
PRAAT_EXECUTABLE=/path/to/praat python -m research.prosody.run development --output reports/prosody/development --executable /path/to/praat
PYTHONPATH=. python reports/prosody/policy_experiments.py
PYTHONPATH=. python reports/prosody/select_development.py reports/prosody/development
PYTHONPATH=. python reports/prosody/assess.py reports/prosody/development
```

Freeze must be committed (including the selected configuration, exact criteria, source hashes and development hashes) before the first blocked invocation. The runner checks the committed freeze and implementation/assessment hashes:

```
PRAAT_EXECUTABLE=/path/to/praat python -m research.prosody.run blocked --output reports/prosody/blocked --executable /path/to/praat
PYTHONPATH=. python reports/prosody/assess.py reports/prosody/blocked
```

`results.jsonl.gz` contains every condition/configuration, native statistics, mathematical error measures, range eligibility, transition evidence and trace hashes. `summary.json` groups by configuration and family; case records retain all rate/PCM/frequency/noise/duration/position conditions. `traces-*.npz` contains lossless double-precision centre times and defined F0 for every case; NaN in this binary audit archive encodes undefined F0, converted to JSON null at the module boundary. NPZ arrays are named by case ID. Other grids, hashes, configurations and source WAV recipes are in the paired case records. WAVs can be regenerated byte-for-byte; no resampling or human-data tuning.

Median and P95 in grouped reports describe the distribution of case metrics, not pooled independent frames. Counts are explicitly summed. Frame overlap means N is not independent sample size. Coverage is defined frames / existing selected frames; edge frame availability is additionally reported against nominal 5 ms sampling cells.

Native statistics are queried on Pitch copies containing ONLY selected centres and all their original candidate blocks. No exterior candidate may enter statistics. Context can still change extraction thresholds/path. The independent oracle rebuilds chosen-only Pitch from the selected frames and queries Praat in a second script/process. Neither script substitutes a frame mean for a native mean or SD. Raw Pitch hashes, restricted Pitch hashes and frame hashes remain auditable.

Temporal support rules test an engineering publication policy; their localized-control labels are not clinical truth or proof that a chosen threshold is optimal. Jump controls test temporal plausibility warnings, not automatic classification of octave errors. No values are corrected.

During pre-freeze development, tests caught overlapping seed ranges and a 20 s WAV exceeding input limits after padding. Seed namespaces were separated; at 20 s exterior context is clipped to the available WAV. Development was restarted after these fixture fixes; blocked was not executed or used for those corrections.

Validation of extraction and calculation is distinct from human prosodic validity. Failed acceptance criteria must remain visible. A frozen blocked run is not a license to retune against that same run.
